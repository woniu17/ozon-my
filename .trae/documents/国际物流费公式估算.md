# 国际物流费按公式 3.37 + 0.0281 × weight_g 估算

## Context

当前 `computeProfit` 预估口径把"代理佣金 + 国际配送 + 其它"打包按 16% 估算,未独立扣减配送费,导致利润高估。需求:把国际配送费(type 67)拆出来按公式 `3.37 + 0.0281 × weight_g` RUB 估算,代理佣金保持 16% 不变。重量来源优先级:妙手称重 > Ozon SKU 重量(按数量加权)。

## 设计决策(用户未明确,基于合理假设)

- **公式单位 RUB**:与 Ozon 应计 type 67 真实口径一致,需 × rate 换 CNY
- **多商品订单按数量加权**:`SUM(oi.quantity × oci.weight_g)` 自动处理
- **重量或汇率缺失时回退原 16% 口径**:保守,避免高估利润,前端按 weightMissing/rateMissing 提示
- **妙手路径复用 `p.weighing_weight`**:妙手 pkg 已带称重,无需查 ozon_cache_index

## 改动文件清单

### 1. `src/db/dao/sqlite/order-daos.js` — 新增重量查询 DAO

**新增 `getWeightsByPackageIds(packageIds)` 函数(L720 附近,listPendingPurchases 前)**:

```sql
SELECT p.id AS packageId,
       mp.weighing_weight AS msWeight,
       (SELECT SUM(oi.quantity * CAST(oci.weight_g AS REAL))
        FROM op_ozon_order_item oi
        LEFT JOIN ozon_cache_index oci ON oci.sku = CAST(oi.sku AS TEXT)
        WHERE oi.ozon_order_id = p.ozon_order_id) AS skuWeight
FROM op_package p
LEFT JOIN miaoshou_package mp ON mp.posting_number = p.logistics_no
WHERE p.id IN (...)
```

返回 `Map<packageId, { weightG, source: 'miaoshou'|'ozon_sku' }>`。全缺失的 package 不入 Map,computeProfit 走 weightMissing 兜底。

**导出**:在 `orderPackageDao` 对象(L1350 区)追加 `getWeightsByPackageIds`。

### 2. `src/modules/order-process.js` — computeProfit 改造 + 4 处路由注入

**a) 顶部常量(L35 旁)**:
```js
const DELIVERY_BASE_RUB = 3.37;
const DELIVERY_PER_G_RUB = 0.0281;
```

**b) `computeProfit` 函数签名(L96)**:
- `computeProfit(pkg, cancelled = false)` → `computeProfit(pkg, cancelled = false, rate = null)`

**c) 预估口径分支重写(L132-143)**:
```js
const commission = round2(orderAmount * DEFAULT_COMMISSION_RATE);
const weightG = pkg.weightG != null ? Number(pkg.weightG) : null;

if (weightG != null && rate != null) {
  // 新口径:配送费独立扣减(对齐真实口径 type 67)
  const deliveryRub = round2(DELIVERY_BASE_RUB + DELIVERY_PER_G_RUB * weightG);
  const deliveryCny = round2(deliveryRub * rate);
  const escrow = round2(orderAmount - commission - deliveryCny);
  const profit = round2(escrow - purchase);
  return {
    commission, delivery: deliveryCny, deliveryRub, escrow, profit,
    profitRateCost: purchase > 0 ? Math.round((profit / purchase) * 10000) / 100 : null,
    profitRateSale: orderAmount > 0 ? Math.round((profit / orderAmount) * 10000) / 100 : null,
    estimated: true, weightG, weightSource: pkg.weightSource || null, rubRate: rate,
  };
}

// 兜底:无重量或无汇率,回退原 16% 打包口径(delivery 隐含在 16% 内)
const escrow = round2(orderAmount - commission);
const profit = round2(escrow - purchase);
return {
  commission, escrow, profit,
  profitRateCost: purchase > 0 ? Math.round((profit / purchase) * 10000) / 100 : null,
  profitRateSale: orderAmount > 0 ? Math.round((profit / orderAmount) * 10000) / 100 : null,
  estimated: true, weightMissing: weightG == null, rateMissing: rate == null,
};
```

真实口径分支(L102-117)和 cancelled 分支(L120-130)**不变**。

## 不变部分(回归基线)

- 真实口径订单(有 accrual 且 rate 存在):走 L103 分支,profit 完全不变
- 已取消订单(`cancelled=true`):走 L120 分支,profit = -purchase 不变
- 预估口径 + 无重量 + 无汇率:走兜底分支,公式与原 16% 等价,profit 不变

## 受影响场景

- 预估口径 + 有重量 + 有汇率:新公式 profit = orderAmount×0.84 − deliveryCny − purchase,比原公式低 deliveryCny 元
- 预估口径 + 有重量 + 无汇率:走兜底,profit 不变,显示 rateMissing
- 预估口径 + 无重量 + 有汇率:走兜底,profit 不变,显示 weightMissing
- /summary "已采购未结算"组总利润合计:有重量的订单利润降低,无重量不变

## 边界情况

- `op_ozon_order_item.sku` 为 NULL:`CAST(NULL AS TEXT)` = NULL,LEFT JOIN 不命中,SUM 忽略 NULL,无问题
- 妙手称重为 0/负值:`ms != null && ms > 0` 守卫过滤,继续走 sku 兜底
- 多 SKU 订单:子查询 SUM 自动按 quantity 加权求和
- 公式系数硬编码:本期硬编码在 order-process.js 顶部,后续可迁 app_config
